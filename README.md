# 📊 财务报表与销售明细管理系统（前端）
本项目是面向中小电商商家打造的轻量级电商经营管理系统前端，基于 Vue3 + TypeScript + TDesign 开发，配套后端采用 Golang 实现（独立仓库维护），主要用于临时替代高成本商用ERP，为预算有限、暂无能力使用专业ERP的中小商家提供一套简单可用的财务与销售数据管理工具。

## 🛠 技术栈
- 核心框架：Vue 3（Composition API）
- 开发语言：TypeScript
- UI 组件库：TDesign Vue Next
- 数据可视化：Apache ECharts

## ✨ 核心功能
### 1. 其他支出管理
- 支持按支出日期筛选各类店铺杂项支出记录
- 覆盖办公用品、水电费、工资等多类支出类型管理
- 提供支出数据的添加、修改、复制、删除全流程操作
- 支持子订单号关联、金额精准录入、备注补充等细节管理

### 2. 产品成本管理
- 支持SKU/商品名称/供应商多维度精准搜索
- 按创建时间筛选产品成本记录，支持数据一键刷新
- 精细化管理采购价、运费、操作费、其他费用等成本项，自动计算总成本
- 支持商品规格、库存、供应商信息维护，数据状态（有效/无效）灵活标记

### 3. 推广支出管理
- 按推广日期筛选推广费用记录，实时统计消耗金额
- 涵盖商品全站推广、关键词推广、人群推广等多类推广类型
- 管理推广计划ID、订单数等核心数据，支持备注补充
- 提供推广数据的添加、修改、复制、删除操作

### 4. 财务报表分析
- 支持昨日/今日/本周/上周/本月/全年/自定义周期数据筛选
- 可视化展示收支对比趋势，核心财务指标（毛利率、净利率）实时呈现
- 展示成本与费用明细、经营表现等关键数据，辅助经营决策

### 5. 销售明细管理
- 支持订单号搜索、实付金额筛选，Excel批量上传导入销售数据
- 对订单执行发货、退款、完成、关闭等状态操作
- 展示商品信息、金额信息、状态信息、时间信息等全维度订单数据
- 支持订单详情查看、删除，退款金额精准管理

## 🔗 后端说明
本项目为前端项目，对应的接口与业务逻辑由独立仓库的 Golang 后端提供，采用前后端分离架构，便于单独维护与扩展。
- 后端仓库地址：https://github.com/DouFu55/taobao-sales-admin-backend

## ⚠️ 注意事项
1. 数据导入规范：
   - 需从千牛后台「已卖出宝贝 - 批量按钮」导出报表，报表类型选择「宝贝销售明细报表」；
   - 必须包含以下字段：子订单编号、主订单编号、商品标题、商品价格、购买数量、商品属性、套餐信息、订单状态、商家编码、订单创建时间、商品ID、商家备注、买家应付货款、买家实付金额、退款状态、退款金额、订单付款时间；
   - 缺失必填字段会导致Excel导入失败或数据解析异常。
